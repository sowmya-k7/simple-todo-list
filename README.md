📝 PHP To-Do List Application

A simple and user-friendly **To-Do List Web Application** built using **PHP**, **MySQL**, **HTML**, and **CSS**.  
This project allows users to add, view, update, and delete daily tasks efficiently.

---

## 📌 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 📋 View all tasks
- 💾 Data stored securely using MySQL
- 🖥️ Simple and clean user interface

---

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP / WAMP / Localhost
